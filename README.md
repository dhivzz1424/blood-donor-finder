\# Blood Donor Finder



Blood Donor Finder is a software engineering project that helps users find suitable blood donors based on blood group and location.



\## Project Features



\- Donor registration

\- Donor login

\- Search blood donors

\- Hospital login

\- Emergency blood request

\- Donation history

\## Future Improvements



\- Add donor location-based search

\- Add emergency blood request notifications

\- Add improved donor availability tracking



## Project Status

The Blood Donor Finder project is currently under development.



\## Donor Search Feature



Users can search for blood donors based on blood group and location.
